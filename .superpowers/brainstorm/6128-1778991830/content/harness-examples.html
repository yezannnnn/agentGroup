GitHub 优秀 Harness 架构参考

看看这些项目如何组织开发流程和工具链，选择你想借鉴的特点

A

Anthropic Claude Code

特点: Skill-based architecture + Hook system

• /skills/ - 标准化能力模块
• settings.json - 统一配置管理
• hooks/ - 事件驱动自动化
• 强制检查点流程
B

Linear (项目管理)

特点: Issue状态机 + 自动化workflow

• 精确的状态流转控制
• 自动分配和通知
• 强类型的Issue模板
• Integration-first设计
C

Nx Monorepo

特点: 任务依赖图 + 缓存机制

• nx.json - 全局任务定义
• 智能依赖分析
• 增量构建和测试
• 工作空间协调
D

Kubernetes

特点: 声明式配置 + Controller模式

• YAML配置标准化
• 状态协调循环
• 资源管理和调度
• 可观测性内置
E

GitHub Actions

特点: 事件触发 + 可组合workflow

• .github/workflows/ - 标准目录
• on: 事件触发机制
• jobs 和 steps 分层
• marketplace生态
F

Bazel (Google)

特点: BUILD文件 + 精确依赖

• 每个包都有BUILD规则
• 最小重构策略
• 确定性构建
• 语言无关抽象

当前 aiGroup 架构对比

缺失: 标准化的skill集成、任务依赖管理、状态机流程
