2. 核心范式组合

A

SDD-First 范式

流程: 先定义Skill → 后设计架构 → TDD实现

优点: 以能力为中心，自然模块化
适用: AI Agent能力开发
B

Harness-First 范式

流程: 先架构设计 → Skill适配 → TDD验证

优点: 稳定的运行时基础
适用: Runtime框架开发
C

混合驱动范式

流程: Skill定义 ↔ Harness设计 ↔ TDD迭代

优点: 灵活适应，双向验证
适用: 复杂AI系统开发

3. Harness架构模式选择

Plugin-Based Harness
harness/
├── core/ # 核心runtime
├── plugins/ # skill插件
├── registry/ # 技能注册
└── lifecycle/ # 生命周期管理
Event-Driven Harness
harness/
├── events/ # 事件总线
├── handlers/ # skill处理器
├── middleware/ # 中间件链
└── orchestrator/ # 编排器
