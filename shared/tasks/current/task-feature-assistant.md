## 功能需求

### 1. 数据库设计（需与Max确认）
需要设计以下数据表，要求：
- 可扩展性：预留字段，支持未来功能升级
- 易用性：字段命名清晰，有完整注释
- 兼容性：不影响现有业务表
- 多租户：所有表必须包含tenant_id

**待设计表**:
| 表名 | 说明 | 需确认字段 |
|------|------|-----------|
| ai_configs | AI助手配置 | 人设、回复策略字段 |
| ai_knowledge_base | 知识库 | 问答对存储、搜索优化 |
| ai_fallback_replies | 默认回复 | 3条异常回复随机 |
| forbidden_words | 禁忌词 | 系统+自定义词库 |

### 2. API开发
- 助手配置CRUD接口
- 知识库管理接口（导入、查询、语义匹配）
- 回复策略接口（频率控制、时间段）
- 禁忌词管理接口

### 3. 前端页面
- Tab页面布局（4个标签页）
  - 人设设置
  - 知识库
  - 回复策略
  - 安全设置
- 保存时检查AI是否关闭

### 4. 侧边菜单修改
- 原"AI消息"改为"智能助手"
- 图标保持或调整为机器人图标

## 开发规范
- 使用SmallInteger而非TINYINT
- 统一响应格式 {code, message, data}
- JWT认证
- 多租户中间件注入tenant_id
- 代码注释完整
